# VS ORGANIC — Pure & Natural Traditional Chekku Oils

Official digital platform for **VS ORGANIC chekku OIL**, founded in 2018. Pure, cold-pressed traditional wood chekku oils and organic kitchen essentials supplied directly to households, retail partners, and supermarkets across 10 branches in Bengaluru and South India.

## Key Features

- **Pure White Atelier Theme**: Clean, high-legibility `#FFFFFF` design adhering to strict brand guidelines (no divider lines, no emojis, no multicolor tags).
- **Full Bilingual Support**: Real-time language switching between **Tamil (தமிழ்)** and **English** with session persistence and Google Translate cookie integration.
- **Entry Language Modal**: Welcome modal on first visit offering seamless language choice.
- **Product Lineup**:
  - Groundnut Oil (*நிலக்கடலை மரச்செக்கு எண்ணெய்*)
  - Sesame Oil (*எள் மரச்செக்கு எண்ணெய்*)
  - Coconut Oil (*தேங்காய் மரச்செக்கு எண்ணெய்*)
  - Pure Cow Ghee (*தூய பசும் நெய்*)
  - Jaggery Powder (*நாட்டு சர்க்கரை*)
  - Traditional Jaggery (*பாரம்பரிய அச்சு வெல்லம்*)
- **Traditional Extraction Process**: 4 cold-pressing steps at <45°C preserving natural vitamins and aromas.
- **Wholesale B2B Estimator**: Real-time quotation calculator and direct WhatsApp inquiry dispatch.
- **10 Regional Branches**: Bengaluru hubs and regional production centers.
- **Zero Mobile Horizontal Scroll**: 100% responsive, optimized for all mobile viewport widths.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS & CSS Variables
- **Icons**: Handcrafted accessible SVGs

## Getting Started

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
npm run start
```
